# Money-Detection
مشروعي هو نظام ذكي لكشف العملات باستخدام نماذج الرؤية الحاسوبية. استخدمت Roboflow لتجهيز البيانات وتدريب نموذج YOLO، والنتيجة كانت موديل قادر يتعرّف على العملات بدقة جيدة. المشروع يشمل:  مجموعة صور للعملات  تعليم البيانات (Annotations)  تدريب نموذج YOLO  اختبار النموذج وقياس الدقة  عرض كامل يشرح خطوات العمل
