# Money-Detection
مشروعي هو نظام ذكي لكشف العملات باستخدام نماذج الرؤية الحاسوبية. استخدمت Roboflow لتجهيز البيانات وتدريب نموذج YOLO، والنتيجة كانت موديل قادر يتعرّف على العملات بدقة جيدة. المشروع يشمل:  مجموعة صور للعملات  تعليم البيانات (Annotations)  تدريب نموذج YOLO  اختبار النموذج وقياس الدقة  عرض كامل يشرح خطوات العمل
ملخص المشروع:  
نظام ذكاء اصطناعي للتعرف على العملات الورقية باستخدام الرؤية الحاسوبية ونماذج YOLO.
يهدف لتحسين الأمان المالي، تقليل الأخطاء البشرية، وتسريع التعاملات النقدية عبر تحليل الصور والتعرف الفوري على العملة وقيمتها.
النظام مناسب للبنوك، المؤسسات المالية، التجار، المسافرين، وذوي الاحتياجات الخاصة، ويمكن تطويره ليعمل على الهواتف، نقاط البيع، أو أجهزة الصراف الآلي.
يعتمد على مراحل: جمع البيانات، معالجة الصور، تدريب النموذج، والتعرف الفوري، مع إمكانية التوسع للكشف عن العملات المزيفة ودعم عملات دولية مستقبلًا.
